# Nikoly Stradiotto — Portfolio

Portfolio editorial para **Nikoly Stradiotto**, estudante de Design Gráfico com foco em ilustração digital, character design e identidade visual.

## Direção visual

- Layout editorial / artbook
- Fundo claro para preservar contraste das ilustrações
- Destaques em vermelho cereja, laranja, dourado, verde e roxo
- Galeria responsiva e assimétrica
- Artes exibidas em seus arquivos originais, sem edição

## Stack

- Angular 17
- SCSS
- GitHub Pages

## Desenvolvimento

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

O build de produção é gerado em `dist/client/browser`.

## GitHub Pages

O workflow em `.github/workflows/deploy-pages.yml` prepara o deploy automático da branch `main` para GitHub Pages.
